## 📖 Estructura del Portafolio (Capítulos)

El sitio está estructurado como una lectura modular por tomos y paneles:

* **CAP. I // Prólogo (Sobre Mí):** Perfil profesional, biografía técnica y estado laboral actual.
* **CAP. II // Disciplines (Habilidades):** Desglose del stack técnico (Frontend, Backend, Bases de Datos y Herramientas).
* **CAP. III // Works (Proyectos & Experiencia):** 
  * `ArtSpace` — E-commerce de arte inclusivo (Angular, Java, PHP, MySQL).
  * `Supermercado Muños` — Experiencia operativa y logística.
  * `SENA & Generation` — Trayectoria académica y bootcamps.
* **CAP. IV // Dispatch (Contacto & Terminal):** Formulario de contacto directo vía terminal integrada con Formspree y accesos a LinkedIn / GitHub.
